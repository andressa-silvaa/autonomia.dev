Implemente `binary_search(items, target)`: `items` é uma lista **ordenada**; devolva o índice de `target` na lista, ou `-1` se ele não estiver lá.

Nada de `in`, `.index()` ou percorrer a lista inteira: os testes fazem milhares de buscas numa lista grande.

```python
binary_search([1, 3, 5, 7], 5)  # 2
binary_search([1, 3, 5, 7], 4)  # -1
```
