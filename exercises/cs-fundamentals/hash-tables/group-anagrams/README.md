Implemente `group_anagrams(words)`, que agrupa as palavras que são anagramas entre si.

- Os grupos aparecem na ordem em que a primeira palavra de cada um aparece.
- Dentro do grupo, as palavras ficam na ordem original.

```python
group_anagrams(["roma", "sal", "amor", "las", "mora"])
# [["roma", "amor", "mora"], ["sal", "las"]]
```
