Implemente `is_balanced(text)`, que diz se os parênteses `()`, colchetes `[]` e chaves `{}` do texto estão balanceados. Os outros caracteres devem ser ignorados.

```python
is_balanced("(a[b]{c})")  # True
is_balanced("([)]")  # False: fecha na ordem errada
is_balanced("((")  # False: ficou aberto
is_balanced("")  # True
```
