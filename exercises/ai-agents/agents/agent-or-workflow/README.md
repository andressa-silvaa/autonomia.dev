Para cada caso, decida: **workflow** (o seu código orquestra os passos) ou **agente** (o modelo decide em laço)? Justifique em duas ou três frases cada um.

1. Ler uma nota fiscal em PDF, extrair cinco campos e gravar no banco.
2. Traduzir 10 mil descrições de produto do português para o inglês.
3. Investigar por que um endpoint começou a devolver erro 500, com acesso a logs, métricas e ao código do repositório.
4. Responder perguntas de clientes com base na base de conhecimento da empresa.
5. Revisar um pull request e comentar problemas encontrados.

Não existe uma única resposta certa para todos, mas existem respostas difíceis de defender. Escolha e defenda.
